# «Давай вместе» — знакомства и сотрудничество в Telegram

Бот помогает людям найти партнёра для совместного проекта, продвижения или профессионального знакомства. Участник заполняет анкету, находит подходящее предложение или человека, отправляет заявку и получает контакт после её принятия.

Все шаги проходят в Telegram: анкета, поиск, сообщение к заявке и решение получателя. Отдельное приложение устанавливать не нужно.

## Два сценария

### Поиск сотрудничества

Блогер, автор канала, заведение или бренд создаёт предложение: что хочет сделать, кого ищет и на каких условиях. Другие участники находят карточку в ленте и откликаются. Автор рассматривает заявки, принимает подходящих участников и получает возможность связаться с ними.

Для этого реализованы профили, пошаговое создание предложения, фильтры, карточки, отклики и решения автора.

### Знакомства на мероприятии

Для фестивального запуска я добавил поиск людей по анкетам: сфера деятельности, цели знакомства, город, описание и фотография. Пользователь выбирает человека, пишет короткое сообщение и отправляет запрос. Получатель может принять или отклонить его; после принятия обоим доступен контакт.

Этот сценарий поддерживает русский и английский языки. Можно скрыть свою анкету из поиска и продолжить начатое заполнение после возвращения в бот.

## Что я разработал

- **Сценарии Telegram-бота:** меню, анкеты, пошаговые формы, ленту предложений, фильтры, заявки и уведомления.
- **Сохранение незавершённых действий:** введённые данные остаются в черновике, а повторный вход возвращает пользователя к нужному шагу.
- **Правила заявок и контактов:** принять или отклонить запрос может его получатель, отозвать — отправитель. Контакт становится доступен участникам принятой заявки.
- **Два варианта продукта в одном боте:** классический поиск сотрудничества и поиск людей для мероприятия, включая русскую и английскую версии фестивального сценария.
- **Надёжную обработку событий:** повторное нажатие кнопки не создаёт вторую заявку, устаревшие кнопки проверяются, изменения и задания на уведомление сохраняются согласованно.
- **Серверную часть и хранение:** SQLite, миграции, очередь уведомлений, запуск через Telegram webhook и размещение на Cloudflare.
- **Проверки полного пути пользователя:** заполнение анкеты, поиск, отправка и принятие заявки, доступ к контакту, перезапуск и обработка повторных событий.

## Опыт реального запуска

Бот использовался для знакомств участников мероприятия. На проверку 8 октября 2026 года в базе были **45 заполненных фестивальных анкет и 19 заявок на знакомство**.

После завершения мероприятия я отключил новые фестивальные знакомства, сохранив анкеты, историю заявок и доступ к контактам по уже принятым запросам. Основной сценарий поиска сотрудничества остался отдельным режимом.

## Технологии и их задачи

| Технология                    | Для чего используется                                                                      |
| ----------------------------- | ------------------------------------------------------------------------------------------ |
| **TypeScript**                | Правила профилей, предложений, заявок и пользовательских сценариев.                        |
| **grammY и Telegram Bot API** | Команды, сообщения, кнопки, фотографии и уведомления.                                      |
| **Cloudflare Workers**        | Приём Telegram webhook и запуск серверной части.                                           |
| **SQLite Durable Object**     | Хранение пользователей, анкет, черновиков, заявок и очереди уведомлений в облачной версии. |
| **Durable Object Alarms**     | Выполнение сохранённых фоновых задач доставки.                                             |
| **SQLite и Node.js**          | Локальный режим, миграции и служебные команды работы с данными.                            |
| **Vitest**                    | Проверки правил, интеграций, полного диалога с ботом и среды Cloudflare.                   |
| **dependency-cruiser**        | Автоматическая проверка зависимостей между модулями.                                       |

## Локальная разработка

Node.js 24.18 или новее в ветке 24, pnpm 11.15.1. Настройки перечислены в [.dev.vars.example](.dev.vars.example); значения и токены хранятся локально вне Git.

```sh
pnpm install
pnpm check
```

Для работы с локальной средой Cloudflare:

```sh
pnpm cloudflare:dev
```

Порядок настройки базы и тестового бота описан в [локальном руководстве](docs/CF1_LOCAL_RUNBOOK.md). `pnpm check` включает линтер, проверку зависимостей и типов, тесты и сборку Node.js-версии; проверки Cloudflare перечислены отдельно в руководстве.
