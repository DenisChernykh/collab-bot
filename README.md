# Collaboration Bot

Telegram-сервис для поиска сотрудничества, создания профилей и обработки заявок на взаимодействие.

## Возможности

- Профили пользователей, предложения сотрудничества и заявки.
- Многошаговые сценарии, сохранение состояния и языковые настройки.
- Cloudflare Worker и SQLite Durable Object для обработки событий.

## Инженерные акценты

- Реализация сложных диалоговых сценариев и сохраняемых пользовательских процессов.
- Управление доступом к контактам и решениями участников.
- Работа с миграциями, повторными событиями и фоновой доставкой.

## Стек

TypeScript, grammY, Vitest.

## Разработка

Инструменты: pnpm@11.15.1.

```sh
pnpm install
pnpm check
pnpm build
pnpm lint
```

Параметры окружения перечислены в [.dev.vars.example](.dev.vars.example). Локальные значения задаются вне Git.
